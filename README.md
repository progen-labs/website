<h1 align="center">Progen Labs: website</h1>

<p align="center"><b>Understand the web. Build it faster.</b><br>Nonprofit · Open source · Free forever</p>

The official website of **Progen Labs**, an open-source lab building free software, tools and learning
experiences for developers. It is live at <https://progen-labs.github.io/website/>.

- **Home**: a 3D hero (the Progen Labs Seed, spinning over its emitter between two light pillars) with
  the lab's projects. Choosing a pillar flies the camera to it.
- **Spectra** (`#spectra`): the frontend performance profiler, with its documentation
  (`#spectra/docs/<page>`) and the two-minute demo film (`#spectra/demo`).
- **The Core** (`#core`): an interactive 3D atlas of how the browser, React and Redux work inside.

Light and dark themes follow the system (with a toggle), and reduced-motion preferences are respected.
Built with **React + Vite**, **three.js** (react-three-fiber and drei) and **Framer Motion**.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
```

## Build

```bash
npm run build    # outputs to dist/
npm run preview  # preview the production build
```

## Deploy

A GitHub Actions workflow (`.github/workflows/deploy.yml`) builds and publishes to **GitHub Pages** on
every push to `main` (Settings → Pages → Source: GitHub Actions). The Vite base is relative, so a custom
domain works too.

## The logo

The Progen Labs mark is the **Seed**: a ribbon that grows from a point, turns a turn and a quarter about
its spine and closes to a point, drawn entirely in straight lines computed from three equations. Its
two faces take two colours, so the twist reads as volume; the animated versions spin it in 3D with a
scan pulse, an orbit and a hologram emitter.

Every version is generated by [`scripts/brand.mjs`](scripts/brand.mjs) into [`public/brand/`](public/brand),
which the site serves at `https://progen-labs.github.io/website/brand/`:

| File | Use |
| --- | --- |
| `progen-seed-emblem.svg`, `progen-seed-emblem-light.svg` | The animated emblem, for dark and light backgrounds |
| `progen-seed-mark.svg`, `progen-seed-mark-light.svg` | The animated mark alone, for headers and small spaces |
| `progen-seed-mark-still.svg`, `progen-seed-mark-light-still.svg` | Still versions, for reduced motion |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser and home-screen icons |
| `progen-labs-avatar.png` | The 800×800 avatar for the GitHub organization and the LinkedIn page |
| `progen-seed-mark.png` | The mark where SVG is not allowed (the VS Code Marketplace) |

The READMEs of every Progen Labs repository load the logo from that address, so changing it here
changes it everywhere:

```bash
npm run brand                                          # the SVGs
npm i --no-save puppeteer-core && npm run brand -- --png   # and the PNGs, with a local Chrome
```

## Structure

```
src/
  App.jsx                 # the routes: home → entering → spectra | core (hash based)
  data.js                 # all Spectra copy (features, usage, frameworks)
  theme.jsx               # light / dark theme
  landing/                # the home page and its 3D hero (LandingScene)
  components/
    ProgenMark.jsx        # the logo in the header
    SpectraWorld.jsx      # the Spectra page
    DemoVideo.jsx         # the demo film overlay
  spectra-docs/           # Spectra's documentation: pages (Markdown), videos, screenshots
  internals/              # The Core: models, scenes and content
scripts/brand.mjs         # generates the logo files in public/brand/
```

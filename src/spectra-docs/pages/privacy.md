- **Everything stays on your machine.** Spectra has no account, no telemetry and no server of its own. Nothing is uploaded; PDFs are printed locally.
- **No install script.** The first time Spectra runs in your project, it adds its [knowledge doc for AI agents](doc:agents) to your project's agent instruction files. It downloads and sends nothing, never does it in CI, never touches text outside its own markers, and is off with `SPECTRA_AGENT_DOCS=0` or `"agentDocs": false`.
- **The dashboard listens on `127.0.0.1` only.** It reads files only inside your project root and refuses path traversal.
- **Credentials stay in memory.** When you [sign in](doc:signing-in), passwords, code secrets, tokens and cookies come from the dashboard or environment variables and stay in memory: they are never written to disk, a report, a log or an error message, and `spectra.config.json` refuses them. A token header goes only to your app's own origin, and Spectra never solves CAPTCHAs.
- **Reports hold details of your app**: file paths, function names and URLs, including query strings that may contain ids. Review a report before sharing it.
- **The page screenshot** (`<id>.page.jpg`) shows whatever was on screen, such as names, numbers or customer data. Treat it like the report. **Delete** in the dashboard removes it with the report.
- **Spectra's Chrome profile** can hold your app's cookies after you sign in. It lives in your temp directory, separate from your own Chrome profile.
- **AI assistants stay local.** The [MCP server](doc:mcp-server) only profiles pages on this machine unless you start it with `--allow-remote`, and its results tell the model that page text is data, not instructions.
- **`spectra improve` sends nothing itself.** Unattended, it runs the coding agent you choose (or finds on your machine); a hosted agent such as Claude Code sends the files it reads to its provider. Its changes stay on a local branch until you merge them. See [Checks and safety](doc:harness-safety).
- **Safe exploration.** The golden-path suite skips destructive controls (delete, pay, log out and similar) and never submits `POST`, `PUT` or `DELETE` forms. See [Golden paths](doc:golden-paths).
- **Only author names** are read from git for comparisons, never email addresses.
